# اجرای بازی یادگیری تطبیقی

این نسخه با **Gemini API** یا **LM Studio محلی** کار می‌کند و منابع را با BM25 محلی برای RAG بازیابی می‌کند.

## اجرای سریع

همه فایل‌ها را در یک پوشه قرار دهید و `run.bat` را اجرا کنید. فایل اجرا Python، محیط `.venv` و پیش‌نیازها را آماده می‌کند و Streamlit را باز می‌کند.

## آپلود PDF با Drag & Drop

در صفحه «تنظیم بازی» می‌توانید یک یا چند PDF را بکشید و در کادر آپلود رها کنید. متن PDF به‌صورت محلی استخراج و همراه URLهای وب وارد یک corpus مشترک RAG می‌شود.

- PDF متنی و Searchable پشتیبانی می‌شود.
- PDF اسکن‌شده یا تصویری که Text Layer ندارد ابتدا باید OCR شود.
- اندازه پیش‌فرض قابل‌خواندن برای هر PDF آپلودی برابر 50 MB است.
- صفحه یا PDF وب تا 20 MB دانلود و ارزیابی می‌شود.
- Streamlit در `run.bat` تا 100 MB برای هر فایل آپلودی اجازه می‌دهد.
- تعداد صفحه قابل‌خواندن به‌صورت پیش‌فرض 500 صفحه است.

تغییر محدودیت‌ها در `run.bat`:

```bat
set MAX_UPLOAD_PDF_BYTES=104857600
set MAX_RESOURCE_BYTES=41943040
set MAX_UPLOAD_PDF_PAGES=1000
```

## پیشنهاد منابع پرمتن مناسب RAG

بخش «یافتن منابع پرمتن مناسب RAG» دیگر فقط لینک صفحه یک دوره را پیشنهاد نمی‌دهد. پس از فشردن دکمه جست‌وجو، برنامه:

1. Wikibooks، Wikiversity، Wikipedia، arXiv، OpenAlex، Stack Overflow و موتورهای جست‌وجوی عمومی را برای chapter، tutorial، handbook، lecture notes، documentation و PDF بررسی می‌کند.
2. هر نتیجه را واقعاً دانلود و متن آن را استخراج می‌کند.
3. صفحات ثبت‌نام، کاتالوگ دوره، سایت‌های ویدیویی و Landing Pageهای کم‌متن را حذف می‌کند.
4. حداقل حجم متن و تعداد واژه را بررسی می‌کند.
5. ارتباط واژگانی محتوا با موضوع را امتیازدهی می‌کند.
6. فقط URL مستقیم صفحه یا PDF قابل‌استفاده برای RAG را نمایش می‌دهد.

هر پیشنهاد تعداد واژه، تعداد نویسه متن و درصد ارتباط را نشان می‌دهد و با یک دکمه به فهرست منابع اضافه می‌شود.

ممکن است بعضی سایت‌ها دسترسی خودکار را مسدود کنند. چنین نتیجه‌ای پیشنهاد نمی‌شود، چون برنامه نمی‌تواند متن آن را برای RAG تضمین کند.

## اجرای محلی با LM Studio

1. یک مدل Chat/Instruct را در LM Studio Load کنید.
2. در تب Developer، Local Server را روی `http://127.0.0.1:1234` روشن کنید.
3. `run.bat` را اجرا کنید.
4. LM Studio را به‌عنوان موتور تولید انتخاب و مدل را تست کنید.

برنامه در حالت محلی به‌صورت پیش‌فرض `max_tokens` یا دستور خاموش‌کردن Thinking ارسال نمی‌کند. Context Length، Max Prediction Length و Thinking تابع تنظیمات خود مدل و LM Studio هستند.

## منابع فارسی و انگلیسی

وقتی زبان فارسی است، موضوع فارسی با همان موتور فعال به عبارت و کلیدواژه انگلیسی تبدیل می‌شود. جست‌وجوی منابع و BM25 با ترکیب عبارت فارسی و انگلیسی انجام می‌شود تا منابع انگلیسی برای موضوع فارسی قابل بازیابی باشند.

## نصب دستی

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app_optimized.py --server.maxUploadSize 100
```

## امنیت و حریم خصوصی

- PDF آپلودی در Session برنامه نگه‌داری می‌شود و به سایت جست‌وجو ارسال نمی‌شود.
- متن PDF فقط به موتور انتخاب‌شده برای استخراج موضوع و تولید سؤال داده می‌شود؛ در LM Studio کاملاً محلی می‌ماند.
- URLها باید عمومی و روی HTTP/HTTPS باشند؛ localhost و شبکه خصوصی برای منابع وب مسدود است.
- متن کامل PDF در فایل JSON نتیجه ذخیره نمی‌شود.
- کلید Gemini و Token محلی در خروجی ذخیره نمی‌شوند.

## سرعت پیشنهاد منابع

بخش پیشنهاد منابع دو حالت دارد:

- **سریع (پیش‌فرض):** موتورهای جست‌وجو هم‌زمان اجرا می‌شوند، نتایج ابتدا از روی عنوان و خلاصه رتبه‌بندی می‌شوند و فقط ۱۰ گزینهٔ برتر با timeout کوتاه دانلود و بررسی می‌شوند.
- **عمیق:** تعداد بیشتری صفحه را کامل بررسی می‌کند و ممکن است زمان بیشتری نیاز داشته باشد.

نتیجهٔ هر عبارت جست‌وجو Cache می‌شود؛ اجرای دوباره همان عبارت و همان حالت باید تقریباً فوری باشد. مقادیر پیش‌فرض در `run.bat` قابل تغییرند:

```bat
set "RESOURCE_DISCOVERY_TIMEOUT=10"
set "FAST_RESOURCE_DISCOVERY_TIMEOUT=6"
set "FAST_RESOURCE_DISCOVERY_WORKERS=8"
set "FAST_RESOURCE_DISCOVERY_BYTES=6291456"
```
